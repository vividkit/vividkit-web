# How ClaudeKit Works - Interactive Guide Teaser

## Overview
VividKit's "How ClaudeKit Works" is an interactive visual guide that demystifies how Claude Code's framework orchestrates Hooks, Skills, Agents, and Workflows to handle complex developer workflows — from fixing bugs to shipping production code.

## Sections

### 1. Hero
- Tagline: "See the invisible engine behind every /ck command"
- ClaudeKit transforms Claude Code from a chat terminal into a professional task automation system
- 20 interactive workflow scenarios, 2 specialized kits (Engineer + Marketing)
- Bilingual: Vietnamese & English

### 2. The Four Pillars
- **Hooks**: Background scripts running automatically — initialize configs, project rules, inject context
- **Skills**: Pre-built knowledge packages (SKILL.md) with prompts, references, scripts — the execution unit behind /ck:* commands
- **Agents**: Specialized models (Planner, Tester, Reviewer) with focused prompts and internal tools
- **Workflows**: End-to-end pipelines chaining Hooks → Skills → Agents from a single command

### 3. Interactive Pipeline Demo
- Visual pipeline with play/pause animation
- Step-by-step execution with detailed explanations
- Terminal-style code snippets for each step
- Sub-agent spawning visualization

### 4. 20 Scenarios Across 2 Kits
**Engineer Kit (13)**: brainstorm, plan, cook, fix, frontend-design, write, ship, code-review, test, deploy, predict, bootstrap, security-scan
**Marketing Kit (7)**: design, seo, campaign, social, email, persona, video
