Vì sao không copy thẳng?

Cấu hình agent là hành vi của cả repo.

Một file instruction sai chỗ, một hook không tương thích, hoặc một skill bê quá rộng đều có thể làm đổi cách agent đọc code, chạy lệnh, xin quyền và sửa file.

01

Instructions

`CLAUDE.md` và `AGENTS.md` đều chứa project guidance, nhưng scope và precedence cần được tách rõ.

02

Hooks

Hook event phải đối chiếu capability; event không hỗ trợ cần suggested fix, không silent copy.

03

Bundles

Skill/agent nên chọn theo vai trò: engineer, QA, content, security, custom; không mặc định gom hết.

04

Rollback

Apply phải có backup manifest vì config migration là thao tác ghi file có blast radius rộng.

Luồng migration

Scan, plan, review, apply, rollback.

Wizard là đường chính cho người dùng; flags giữ parity cho CI và power users. Mọi write đi qua plan trước.

Kiến trúc adapter

Core engine không bị khóa vào một provider.

MVP implement Claude source và Codex target. Các provider khác tồn tại như roadmap adapter với unsupported findings, tránh nói quá là đã migration-ready.
